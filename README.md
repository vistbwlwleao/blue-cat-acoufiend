## Overview

Blue Cat AcouFiend simulates acoustic resonances of physical spaces and instrument bodies, adding realistic coloration to direct recordings and synthetic sources.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat AcouFiend** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Resonance Modes** | String, plate, room, and body resonance simulation modes |
| **Tuning** | Adjustable resonance frequency for matching the source material |
| **Decay Control** | Attack and decay shaping of resonance response |
| **Wet Mix** | Dry/wet blend for subtle enhancement or full resonance processing |
